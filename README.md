# KSB Assistent

Seitenleiste für das klassische Outlook des Künstlersekretariats Buchmann. Enthält nur die Oberfläche, keine Daten und keine Schlüssel. Die führende Fassung liegt im Leitstand-Repository unter `outlook-seitenleiste/`.

## Tourneepläne

Unter `tournee/` liegen die Online-Tourneepläne des Wiener KammerOrchesters (zuerst `tournee/hanoi-2026/`). Auch sie enthalten nur die Oberfläche: Die Daten kommen erst nach der Anmeldung per E-Mail-Code von der Funktion `hanoi-login` (Supabase). Dieser Ordner wird nicht aus dem Leitstand gespiegelt und darf beim Abgleich der Seitenleiste nicht gelöscht werden.
